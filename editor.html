동작 포즈

PIPELINE

수정이 반영되는 과정

1. 모델 고르고 요청 보내기

버튼으로 모델을 고르고 레퍼런스·프롬프트를 넣어 "요청 보내기". 요청과 파일은 이 페이지의 저장소에 모델별로 남아요.

2. 채팅에서 확인 부탁

채팅에 "요청 확인"이라고 보내주세요. Claude가 새 요청을 모두 읽고 레퍼런스를 내려받아 직접 봅니다.

3. 스펙·모델링 수정 → Blender

숫자·색은 assets/specs/<모델>.json에, 모양 변화는 모델링 스크립트에 반영하고 node tools/build-character.mjs <모델>로 다시 만들어요.

4. 같은 링크 갱신

새 모델·렌더로 편집기가 업데이트되고, 요청 기록에 "반영 완료"와 무엇을 바꿨는지가 적혀요. 새 모델은 버튼이 하나 늘어나요.
