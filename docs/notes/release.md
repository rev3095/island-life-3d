## 사용자 손 점검 (RC-05 · 06 · 07 · 08 · 11 · 12)

한 번에 하려면 이 순서가 빠르다. 결과는 게임 안 섬폰 「문제 알리기」나 채팅으로.

1. **RC-05** — PC 의 claude.ai 에서 게임 링크를 연다 → 로딩 화면 → 「시작」 → 섬이 보이고 소리가 나는지, WASD·Space·I·P·M 키가 듣는지.
2. **RC-07 · RC-08 · RC-06** — 같은 링크 끝에 `#check` 를 붙여 연다 (30초 기기 점검, 결과가 게임 저장소 `checks` 에 남는다):
   다른 GPU 의 PC 한 대 · iPhone 한 대 · Android 한 대 (휴대폰은 와이파이를 끄고 데이터로 — 로딩 시간이 RC-08). 휴대폰은 이어서 링크를 그냥 열어 세로·가로로 조금 걸어 보기 (패드·A·B·도구 고리).
3. **RC-11** — PC 에서 섬폰 「저장 옮기기」 → 파일로 내보내기 → 다른 브라우저(또는 휴대폰)에서 같은 링크 → 섬폰 「저장 옮기기」 → 불러오기 → 이어지는지.
4. **RC-12** — 다른 계정(또는 시크릿 창)으로 링크를 열어 새 게임이 따로 시작되는지 (내 저장이 안 보여야 정상).

끝나면 채팅에 "출시 점검 결과" 와 함께 알려 주면, `checks`·`reports` 를 읽어 이 표를 채우고 → 공유(D36)는 사용자가 정한다.
