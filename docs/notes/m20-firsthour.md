# M20-S1 첫 30분 다듬기 (브랜치 `m20-firsthour`, 포트 4311)

목표: 처음 하는 사람이 게임을 열고 30분 안에 막히지 않고, 섬이 좋아지게. 결정 번호 D260–D264 는 쓰지 않았다 (큰 구조 변경 없음 — 아래 「제안」).

## 지금 첫날 흐름 (코드로 따라감)
배 도착 s01 (`newgame`) → 이름 정하기 창 (`intro/naming.js`, 차근차근/짧게) → 선착장 밤톨 첫 안내 (`town/keepers.js introFlow` → `town:intro`) → s02 (`guide-done`, 짧게면 안 나옴) → 왼쪽 「첫날 할 일」 7단계 (`intro/rules.js STEPS`, 이벤트로만 체크) → 다 하면 「밤톨에게 알려 주기」 → 밤톨 선물 (라디오 + 🌰1,000, `claimReward` → `intro:reward`) → s03 (`firstday-done`) → **다음 날** s04 (`newday` after s03) → `festival:started` → 축제 준비 힌트 카드.

## 제안 (큰 구조 — 이번엔 안 함)
1. **섬폰 앱 단계적으로 보이기**: 섬폰 메뉴에 처음부터 앱이 많다(일지·별점·앨범·달력·꾸미기·옷장…). `phone.js APPS` 에 `opensAfterDay` 같은 칸을 두고 처음 소개 카드와 같은 날 켜지면 첫 화면이 가벼워진다. ui 트랙(S2 가 `ui.css` 를 고치는 중)과 겹쳐 이번엔 안 했다.
2. **투어 배·망원경·우편함**도 첫날엔 「아직이에요」 대사로 2–3일째부터 열면 좋다 — 각 모듈 행동 키 test 에 같은 `introDay` 조건. 지금은 스스로 찾을 때만 보여 쏟아지지는 않는다.
3. 섬 별점 첫 알림이 선물 날 바로 뜰 수 있다 (`rating/index.js live`). 상이 도토리라 기분 좋은 알림이라 그대로 뒀다 — 겹치면 일지처럼 `startsNextDay`.
4. 막힘 시간(2분 30초)은 처음 하는 사람 실제 기록이 없어 짐작 값 — `rules.js STUCK` 한 곳.
