## M9-P2 — 섬 꾸미기 틀 (D86-A, UI-16 · UI-17)

- **여는 법**: 섬폰 「🪴 섬 꾸미기」 (섬폰은 닫힌다) → 화면 아래 칸(휴대폰은 아래 꽉 차게). 실내에선 「밖에서 해요」.
- **조작**: 앞 칸(바라보는 방향 네 쪽 중 가까운 쪽)에 놓는다. Space(A) 놓기 · Q/E(또는 F, 「돌리기」 단추) 돌리기 · Tab 다음 것 · X 「고치기」(앞의 것 치우기·제자리 돌리기) · Esc 끝. 마우스로 걸으며 해도 된다.
- **미리 보기 (UI-17)**: 발자국 둘레 테두리 + 옅은 바닥(놓을 수 있음 초록 · 없음 빨강 · 고치기 대상 노랑 · 대상 없음 회색) + 반투명 모델(가림 투명 디더, 길·울타리는 이어질 팔까지).
- **칸 판정** (`decor/rules.js` `canPlace`, 테스트 있음): 풀밭·모래·흙길만 (광장·물·절벽·비탈·다리·선착장 안 됨) · 발자국이 같은 높이 · 물체가 없을 것(길 위에 울타리·가구는 됨, 길 위에 길은 안 됨) · 집·상점·박물관 문 앞 3×2 칸과 빈 집터 둘레(이사용)는 비움 · 서 있는 칸 · 한도 400.
- **이어짐**: 같은 종류 이웃 넷(+ 길은 모서리) → 변형 꼬리표 `+n+e…`. 놓고 치울 때마다 그 칸 둘레 3×3 을 다시 맞추고, 시작할 때 한 번 모두 다시 맞춘다(예전 저장·받는 중에 놓인 것).
- **놓을 것**: 길 넷·울타리 둘은 거저(한도만), 야외 가구는 가방에서. 가방의 가구 중 아이템 `outdoor: true` — 새 FU-47–50 + 지금 가구 아홉(모닥불·통나무 의자·통나무 테이블·화분·장작더미·서핑보드·수확 바구니·눈사람 등·벚꽃 등). FU-47–50 은 상점 가구 후보(`source: 'shop'`, 살 값 1000–2400).
- **주민**: 길찾기에서 깐 길 칸 = 흙길 값(0.75), 울타리는 충돌이라 돌아간다. 가끔(20%) 벤치·피크닉 탁자 앞에 가서 선다 (앉는 동작은 없음 — 다음에).
- **저장**: world 의 `state.island.added` 그대로 (새 칸 없음). 1.2초 뒤 저장. 개발판에서 놓고 새로 고침 → 그대로 남는 것 확인.
