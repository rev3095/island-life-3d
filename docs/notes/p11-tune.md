## 찾은 버그 (막힘 — 먼저 합칠 것)
**장면 층이 장면이 없을 때도 마우스·터치를 다 막았다.** `src/gameplay/story/story.css` 의 `.st-root { pointer-events: none }` 을 `index.html` 의 `#ui > * { pointer-events: auto }` (id 가 들어가 더 셈)가 덮어서, 화면 전체를 덮는 장면 층(z-index 40)이 늘 클릭을 가로챘다. 새 게임 이름 창의 🎲·글자 칸·「이대로 정할래요」도 마우스로 안 눌렸다 (Enter 키·Tab 은 됐다). 자동 플레이 봇은 DOM `.click()` 으로 눌러서 QA 가 못 잡았다. 게시본(v12)도 같은 `index.html` 을 쓰므로 같을 것.
→ 커밋 `a67a344`: `#ui > .st-root:not(.is-on) { pointer-events: none; }` 한 줄 + 테스트(`tips.test.mjs` 마지막). 스토리 트랙 파일이라 따로 커밋해 두었다 — P6 합치기 때 이 커밋만 먼저 가져가도 된다. intro 는 같은 이유로 `#ui > .fd-root { pointer-events: none }` 을 이미 갖고 있었다.

## 한 일

### 1. 막힌 곳 힌트 (힌트 카드)
화면 오른쪽 위(메뉴 단추 밑, 휴대폰 세로는 할 일 목록 밑)에 14초 동안 뜨는 카드 — 아이콘 · 제목 · 한두 문장 · "섬폰 💡「안내」에서 다시 볼 수 있어요" · 「알겠어요」. 이모티콘 대화·대사 중에도 보이고(말풍선·선택기를 안 가림), 가방·섬폰·확인 창이 열리면 내려가고, 장면이 시작되면 내렸다가 끝난 뒤 다시 뜬다. 글자 배율(`--pk-fs`)·흔들림 줄이기(`pk-calm`)를 따른다.

판정은 그대로 두고 **결과를 보고** 알려 준다 — `festival:emote {slug, keys, kind}` 를 주민 파일 `emote.rule` 과 맞춰 본다 (`tips.js missesOf`). 같은 힌트의 같은 단계는 한 번만, 더 막히면 더 또렷한 단계. 그 주민과 기쁨·아주 기쁨이 나오면 그 주민 힌트는 그만.

### 2. 안내 건너뛰기
- **이름 정하기 창(새 게임만)에 「첫날 안내」 고르기**: `차근차근`(밤톨 설명 + 첫날 할 일, 기본) / `짧게`(해 본 적 있어요). 확인 창에도 고른 것이 나온다. 이름 다시 정하기·예전 저장에선 안 보인다.
- `짧게`: 밤톨 첫 안내(town `introFlow`)의 첫 말을 `SHORT_INTRO` 세 줄로 바꾸고 나머지 말(조작 설명·할 일 목록 설명)은 바로 넘긴다 — intro 의 `ui.dialog.open` 감싸기 안에서, 밤톨 이름 + `!flags.intro` + `firstday.skip === 'short'` 일 때만. 끝나면 할 일 목록 없이 바로 건너뛰기(아래).
- **할 일 목록 머리의 ✕**: 다 안 했으면 확인 창("목록을 치우고, 밤톨에게 바로 환영 선물을…") → 건너뛰기. 다 했으면 묻지 않고 치운다.
- 건너뛰기(`skipRest`) = `firstday.skipped = 그날`, `hidden`, `finished`(→ `intro:done {skipped: true}`), `intro:skip {why}`. 한 일 기록 `done` 은 그대로 둔다. **밤톨 선물(라디오 + 🌰1,000)과 s03·s04 → 축제 이야기는 그대로 이어진다** (선물은 밤톨에게 말을 걸면, 그 뒤 `intro:reward` → s03 → 다음 날 s04). 건너뛰면 진행이 막히지 않게 하려고 '다 마친 것'으로 친다.

### 3. 밤에 시작한 첫날 (QA-09, 규칙은 그대로)
상점이 닫혀 있으면(`economy.isOpen`) 목록의 '지금 할 일'이 '팔기'를 건너뛰어 다음 빈칸(기증·집)부터 가리키고 `night` 힌트를 한 번. 남은 게 팔기뿐이면 팔기(문 닫힘 안내 그대로). `rules.js` `currentStep(p, blocked)`·`viewOf(p, {blocked})` (`ahead` = 건너뛰었나). **선물·s03 은 여전히 팔기까지 해야 해서 하루 밀리는 것은 그대로** — 첫날만 밤톨이 문 너머로 사 주기는 town(`keepers.js`) 몫이라 7차 보드 QA 칸에서.

### 4. 섬폰 「💡 안내」
- 섬폰 메뉴 줄: `src/ui/phone.js` `APPS` 에 `{ id: 'guide', name: '안내', icon: '💡', panel: 'guide' }` 한 줄 (P3 의 `panel` 방식 — `ui.guide.open` 이 있을 때만 보임). 창은 intro 가 `ctx.services.ui.guide = { open }` 으로 채운다 (`EXTRA_PANELS` 의 "모듈이 스스로 채웠으면 그것을 쓴다" 길). `src/ui/index.js` 는 안 고쳤다.
- 창(`guide.js openGuide`, `ui.panel('guide', …)` 로 섬폰 위에 쌓임): ① 첫날 할 일 7개와 하는 법(키보드/터치 글), 한 것 ✔, 「왼쪽 목록 다시 띄우기 / 치우기」 ② 조작 — 「밤톨 설명 다시 듣기」(밤톨 `intro.keys`/`touch` 대사를 대화창으로) ③ 축제 이야기가 시작된 뒤 부품 주민 다섯의 친밀도 막대 · 💗 n/30 · 💬 n/2 · 부품 받음 ④ 지난 힌트(새 것부터, 친해지기는 지금 값으로).
- 건너뛴 뒤 목록을 다시 띄우면 '지금 할 일' 대신 '🎁 밤톨에게 알려 주기'만 강조 (`viewOf`: `finished` 면 단계 강조 없음).
