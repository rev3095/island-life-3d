## 3. 봇 빈칸 — 살랑 미술품을 못 삼 → fake-art 건너뜀

- 01-06 결과: 살랑이 11-15 밤에 왔고 진열 셋이 모두 가품(`three-pears-fake` · `big-acorn-fake` · `star-river-fake`)이었는데 봇 도토리가 모자라(값 🌰4,000–5,600) 못 샀다 → fake-art 「가방에 가품 미술품이 없음」 건너뜀.
- 고침 (사람처럼, 지름길·상태 고치기 없음):
  - 돈 모으기 `earnUntil(target)` (새, decor 의 QA-10 돈 벌기를 꺼냄): 낚시 · 과일 흔들기(저녁엔 곤충) → 상점에 팔기를 목표가 될 때까지.
  - night-shops: 밤마다 살랑 가게에서 작품을 하나씩 「보기」 → 살랑 말투로 가품을 알아챈다(`색이 특별하지콩` · `독특한 판` · `묘한 맛` — night.json `lines.salang.fake`). 가품이고 돈이 되면 「살게요」, 모자라면 「그만둘래요」 하고 **들은 값을 목표로** 다음 날 낮에 벌어 둔다. 아직 값을 못 들었으면 미술품 값 아는 만큼(가장 비싼 값) 모은다. 진품만 있는 밤은 사지 않고 나온다. 가품을 사거나 9일이 차면 끝 (예전: 살랑·천막이 한 번 오면 끝).
  - 결과 칸에 `foxNights`(밤마다 들은 것·값·산 것) · `earn`(날마다 번 돈).
