# X3 첫날 흐름 — 작업 노트 (`p6-firstday` 브랜치)

새 게임: **이름 정하기**(내 이름·섬 이름) → 밤톨 첫 안내(이름으로 부름) → 왼쪽 위 **첫날 할 일** 목록 7단계 → 다 마치면 **밤톨이 축하하며 선물**(라디오 + 도토리 1,000).
확인: `node dev-server.mjs --port=4197` → `/index.html?debug`. 새 게임은 콘솔에서 `__island.services.data.save.reset()` 뒤 새로고침.

## 만든 것

| 파일 | 내용 |
|---|---|
| `src/gameplay/intro/index.js` | 모듈 입구 (`name: 'intro'`). 이름 정하기 띄우기, 진행 알아채기(이벤트), 목록 갱신·화살표, 저장, `ctx.services.intro`, 대화창 `{player}`·`{island}` 채우기 |
| `intro/rules.js` | 순수 규칙 (DOM 없음): 이름 다듬기·확인, 조사(숫자 이름 포함), 이름 자리 채우기, 단계 표·진행 기록·예전 저장 추정·안내 문구·목록 보기 |
| `intro/naming.js` | 이름 정하기 창 (자기 DOM). 한글 입력·글자 수·🎲 추천 → `ui.confirm` 로 한 번 더 확인 ('다시 정할래요' 면 창으로) |

## 흐름

1. **이름 정하기** — `game:ready` 때 `state.player.name` 이 비어 있으면 창을 띄운다. 창이 떠 있는 동안 `input.enabled = false`, 창 밖으로 가는 키는 막고(Tab 은 창 안에서만), 휴대폰 A/B·조이스틱은 창 밑에 깔린다. '이대로 정할래요' → `ui.confirm`(내 이름·섬 이름, "한 번 정하면 바꿀 수 없어요") → 좋아요 = 저장 / 다시 정할래요 = 창으로 돌아감 (값은 남는다). 저장은 바로 `data.save.save()`.
2. **밤톨 첫 안내** — town 이 `ctx.services.intro.holding` 이 true 인 동안 기다렸다가 창이 닫히고 0.9초 뒤 말을 건다. 대사는 이름으로: "어서 와요, 윤슬 씨! 몽글섬에 온 걸 환영해요!". 끝에 목록 얘기 두 줄 (`intro.list`, intro 모듈이 있을 때만). `town:intro {done}` → 목록이 뜨고 "첫날 할 일이 생겼어요!" 알림.
3. **첫날 할 일** — 순서대로 보여 주지만 **어느 순서로 해도 기록**된다 (지금 할 일 = 맨 앞 빈칸). 단계를 끝내면 "○○ 완료! (n/7)" 알림 + 체크 튀기기 + 다음 단계 안내.
4. **다 마침** — `intro:done` + "첫날 할 일을 모두 해냈어요! 밤톨에게 알려 줘요" → 목록 맨 아래 "🎁 밤톨에게 알려 주기".
   - 집 안에서 마쳤으면(보통 마지막이 '집 들어가기') 밤톨이 **집 문 옆으로 와서 기다리고**, 나오면 0.9초 뒤 먼저 말을 건다 → 선물 → 가게로 걸어 돌아간다.
   - 밖에서 마쳤으면 상점 문·밤톨 앞에서 행동 키 (우선순위 95, 상점 90 보다 앞). 문 닫은 시간이면 밤톨이 잠깐 나왔다가 다시 들어간다.
   - 가방이 꽉 차면 "한 칸 비우고 다시 말 걸어 줘요" → 선물은 남아 있고, 다음엔 짧은 대사(`firstday.again`)로 준다.
   - 선물을 받으면 `intro:reward`, 목록이 6초 뒤 치워진다 (`hidden`).

## 첫날 할 일 7단계 — 알아채는 신호

없는 이벤트는 만들지 않고 지금 있는 이벤트로 알아챈다 (아래 '부탁' 의 전용 이벤트가 생기면 바꾸기 쉽게 `index.js` 한 곳에 모았다).

| 단계 | 화면 글 | 알아채는 것 | 화살표 |
|---|---|---|---|
| `intro` | 밤톨 이야기 듣기 | `town:intro {done}` (저장에서 이어하면 `flags.intro`) | 밤톨 |
| `tool` | 도구 들어 보기 | `player:tool {tool}` 이 null 이 아님 | — |
| `gather` | 나무 흔들기나 줍기 | `sfx {shake}` (나무 흔들기는 gather 만 냄), `sfx {pickup|acorn}` 인데 창·대화가 없고 얼어 있지 않고 집 밖 (주민 선물·편지·가구 줍기를 빼려고) | — |
| `catch` | 물고기나 곤충 잡기 | `sfx {catch|bug-catch}`, `encyclopedia:changed` (물고기·곤충) | — |
| `sell` | 밤톨 상점에서 팔기 | 상점 창(`ui:open {panel:'shop'}` ~ `ui:close`)이 열린 동안 `wallet:changed` 가 늘어남 | 상점 문 |
| `donate` | 느루에게 기증하기 | `museum:changed {id}` | 박물관 문 |
| `home` | 내 집에 들어가 보기 | `house:enter` (집 안에서 이어하면 바로) | 내 집 문 |

화살표는 카메라가 보는 방향 기준(화면 위 = 앞)으로 돌고, 4칸보다 가까우면 숨긴다. 집 안에서는 숨긴다.

## 정한 것

- **이름**: 내 이름 1~8글자, 섬 이름 1~6글자 + '섬' (끝에 '섬'을 적으면 하나만 남김 — '포근섬' → '포근섬'). 한글 완성 글자·영어·숫자·빈칸만 (앞뒤 빈칸 빼고, 여러 칸은 하나로). 홑자모('ㅎㅎ')는 "글자를 끝까지 완성해 주세요". `{`·`<` 같은 글자는 못 써서 대사 자리 표시와 섞이지 않는다. 섬 이름 처음 값은 '포근'. 🎲 추천은 새로 지은 우리말 (하늘·윤슬·다온… / 몽글·별빛·소복…).
- **한글 입력**: 조합 중(`isComposing`)인 Enter 는 무시, 넘친 글자는 조합이 끝난 뒤에만 자른다. Enter = 다음 칸 → 정하기. 휴대폰은 글자판이 덮으니 자동 포커스를 하지 않는다.
- **이름을 대사에**: intro 가 `ui.dialog.open` 을 감싸서 `lines`·`choices`·`speaker` 의 `{player}`·`{island}` 를 채운다 (`{player:아}`·`{island:은}` 처럼 조사도). town 의 `fill` 은 모르는 자리를 남기므로 주민·편지 대사에 이 자리를 넣기만 하면 된다. 밤톨 흐름은 keepers 가 `speaker` 에 이름도 직접 넘긴다 (intro 가 없어도 기본값 '친구'·'포근섬').
- **예전 저장** (첫 안내는 들었는데 `flags.firstday` 가 없음): 한 것으로 보이는 단계는 건너뛴다 — 잡은 적 있음 = 잡기, 기증 = 기증, 집에 들어가 봤음(`house.seeded`) = 집, 가방에 도구 말고 뭐가 있거나 땅에 떨어진 물건 = 줍기, 도구를 들고 있거나 잡기/기증 = 도구. 판 기록은 남지 않아서 **잡고·기증하고·집까지 가 본 저장은 다 한 것으로** 보고 목록을 아예 띄우지 않는다 (`finished: 'legacy'`, 선물 없음). 이름이 없으면 예전 저장이라도 이름 창은 한 번 뜬다 ("아직 이름이 없네요!").
- **보상**: `furn.radio`(라디오, 상점가 2,000) + 도토리 1,000 — 첫 판매 값(물고기 몇 마리)보다 커서 삽·도끼 하나를 살 수 있다. `rules.REWARD` 한 곳.
- **목록 자리**: 왼쪽 위 시계 아래 (`top 96px`, 휴대폰 세로 `84px`·너비 184px — 오른쪽 위 메뉴 단추에 안 닿게, 360px 아래는 메뉴 밑 `112px`). ui 층 **밑**에 넣어서 알림·창이 위로 덮는다. 상점·가방 같은 창이 열리면 숨기고, 대화 중엔 보인다. 터치이거나 640px 아래면 처음엔 접힌 채 (지금 할 일만), 접기는 `flags.firstday.collapsed` 에 저장.
- **이름 창 자리**: ui 층 위·휴대폰 조이스틱 위 (`#ui` 맨 끝). 확인 창(`ui.confirm`)이 뜨는 동안은 이름 창을 숨긴다.
- **키보드·터치 문구**: 단계 안내는 `input.touch` 에 따라 (Space·F·숫자키 ↔ A·B·도구 단추), 밤톨 첫 안내는 원래대로 `touch`/`keys` 묶음.

## 상태·이벤트·서비스 — 계약 제안 (`docs/CONTRACTS.md` 에 '3차 X3 첫날 흐름' 절로)

### 상태
| 칸 | 주인 | 내용 |
|---|---|---|
| `player.name` | gameplay·intro | 플레이어 이름 (core `createState` 에 이미 있던 빈 칸). player 모듈은 읽기만 |
| `island.name` | gameplay·intro | 섬 이름 '…섬' (없으면 대사엔 '포근섬') |
| `flags.firstday` | gameplay·intro | `{ v, done: { 단계id: dayKey|true }, finished: dayKey|'legacy'|null, rewarded, hidden, legacy, collapsed }` |

`flags`·`player`·`island` 는 `createState` 에 있는 칸이라 `save.reset()` 때 같이 지워진다 (새 최상위 칸을 만들면 reset 이 안 지운다 — `applyTo` 가 source 의 칸만 덮기 때문. town 의 `state.mail` 이 그렇다 → T2 에 알림).

### 서비스 `ctx.services.intro`
```js
holding            // 이름을 정하기 전 (town 이 밤톨 첫 안내를 미룬다)
names() → { player, island },  fill(text)          // 이름 자리 채우기
current() → 단계id | 'reward' | null                // 목록이 떠 있을 때 지금 할 일
rewardPending() → bool,  reward: { item, acorns },  claimReward()   // town keepers 가 선물을 준 뒤 부른다
progress()                                           // 기록 복사본
// 개발용: complete(id), rename(), reset()
```

### 이벤트
| 이벤트 | 내용 |
|---|---|
| `intro:named` | `{player, island}` 이름을 정했을 때 |
| `intro:step` | `{id, n, total}` 단계 하나 끝 |
| `intro:done` | `{dayKey}` 7단계 다 끝 (town 이 집 앞 방문을 정한다) |
| `intro:reward` | `{item, acorns}` 밤톨 선물을 받음 |

### 행동 키
| 이름 | 우선순위 | 언제 |
|---|---|---|
| `town:firstday` | 95 | 선물이 남았을 때: 집 앞에 온 밤톨 2.2칸 안, 또는 상점 문·밤톨 앞 (상점 90 보다 앞) |

## 대사 (밤톨, `lines/bamtol.js`)

- 바꾼 것: `intro.hello` — "어서 와요, {player} 씨! {island}에 온 걸 환영해요!", "오늘부터 {island:은} {player} 씨의 섬이기도 해요. …". `intro.after` — "{island}에는 주민이 여섯 명 살아요…", 끝의 "가게로 먼저 가 있을게요" 는 `intro.bye` 로 뗐다. `intro.touch` — 도구 단추 줄 추가 ("도구는 오른쪽 도구 단추를 누를 때마다 바뀌어요", "가방·지도·섬폰은 화면 오른쪽 위 단추에 있어요"). `letters.welcome` — "{player} 씨, {island}에 온 걸 다시 한번 환영해요!".
- 새 것: `intro.list` (2줄: 화면 왼쪽에 적어 뒀어요 / 다 마치면 알려 줘요, {player} 씨를 위한 선물), `intro.bye`, `firstday.sell` (2: '팔래요'를 골라 봐요), `firstday.visit` ("{player} 씨! 집 구경은 잘 했어요? 여기서 기다리고 있었어요!"), `firstday.done` (3: 전부 해냈네요 / 어엿한 {island} 주민 / {item:이랑} 도토리 조금), `firstday.after` (2: {item:은} 집에 놓고 / 앞으로도 {island}에서), `firstday.full`, `firstday.again`.
- 알림 문구 (intro): "첫날 할 일이 생겼어요! 왼쪽 목록을 봐요", "○○ 완료! (n/7)", "첫날 할 일을 모두 해냈어요! 밤톨에게 알려 줘요".

## 다른 트랙에 부탁

- **주민 대사에 이름 (W2 town 몫, 조정 세션이 합칠 때)**: 공유 노트 폴더 `firstday-villager-names.patch` — 주민 6명 자기소개 첫 줄과 느루 첫 방문 첫 줄에 `{player}` 를 넣고 (`이름이 {player:이라고}?`, `새로 온 {player:이구나}멍` …), `tests/town.test.mjs` 의 자리 이름 목록에 `player`·`island` 를 더한다. `git apply` 로 붙이면 `node --test tests/` 124개 그대로 통과. 이 브랜치엔 넣지 않았다 (고칠 수 있는 파일 밖).
- **X1 (ui)**: ① 지금은 intro 가 `ui.dialog.open` 을 감싸서 이름을 채운다 — ui 가 `dialog` 안에서 `state.player.name`·`state.island.name` 으로 직접 채우게 되면 이 감싸기를 지우면 된다 (감싼 표시 `ui.dialog.namesFilled`). ② HUD·섬폰에 이름 보이기 (섬폰 첫 화면 "몽글섬 · 윤슬" 같은), 섬폰 설정에서 이름 다시 정하기를 넣는다면 `ctx.services.intro.rename()` 을 부르면 된다 (지금 창은 "바꿀 수 없어요" 라고 말한다 — 넣으면 그 문구도 같이). ③ 시계 크기·자리를 바꾸면 목록 `top`(`intro.css` `.fd-list`)도 맞춰야 한다 — `--pk-hud-left-bottom` 같은 CSS 변수를 주면 그걸 쓰겠다. ④ 휴대폰에서 알림(`.pk-toasts`, top 118px)이 목록 위를 지나간다 (알림이 위라 가려지진 않음).
- **W1 gather (다음 정리 때)**: 줍기·나무 흔들기·잡기를 효과음 이름과 '창·대화 없음' 조건으로 알아채고 있다. `gather:shake {id}`, `gather:pickup {id, item}`, `gather:catch {id, kind:'fish'|'bug'}` 같은 이벤트가 생기면 `intro/index.js` 의 `sfx` 처리 세 줄을 바꾸면 된다.
- **T3/X1 shop**: 판매는 '상점 창이 열린 동안 도토리가 늘어남'으로 알아챈다. `shop:sell {id, n, acorns}` 이벤트가 있으면 더 정확하다.
- **T2 data**: `save.reset()` 이 `createState` 에 없는 최상위 칸(town 의 `state.mail`)을 지우지 않는다 → 새로 시작해도 예전 편지가 남을 수 있다. intro 는 `flags`·`player`·`island` 안에만 둬서 괜찮다.
- **X4 (웹 배포)**: intro 는 `new URL('./intro.css', import.meta.url)` 로 CSS 를 붙인다 (ui 와 같은 방식) — 묶을 때 `src/gameplay/intro/intro.css` 도 같이 넣어 주세요. 새 그림 파일은 없다 (이모지만).
- **X2**: 고칠 것 없음. 화살표는 `ctx.camera.getWorldDirection` 으로 화면 위 방향을 잡으니 카메라 각도를 바꿔도 그대로 맞는다.
