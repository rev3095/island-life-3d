## 보드와 달라진 것 (반영하며 정함 — 보드 카드도 고쳐 다시 게시)

- **달빛 가게 자리**: 보드는 「광장 동쪽 언덕」. 지금 섬(layout.json)은 나무가 빽빽해 동쪽 언덕엔 3×3 빈 곳이 없어 **광장 북쪽 언덕(박물관 서쪽)** 에 선다. 집터 4×3 은 섬 전체에 두 곳뿐이라 모델을 0.85 배로 줄여 3×3 (BD-08 v0.2).
- **새벽 천막 자리**: 「동쪽 숲 끝」 → 남동쪽 숲(도토리상점 남쪽). 다른 건물 문 앞마당·집터는 피한다.
- **타로 효과**: 「밤 곤충 더 자주 · 망원경 소원 · 꽃 더 피어남 · 화석 자리 하나 더 · 걷기 빠르게」는 출현표·지도를 바꿔야 해서 값·출현 고리 하나(`data.luck`)로 할 수 있는 것으로: TA-02 달님 곤충 팔 때 +25% · TA-03 별 감정에서 귀한 화석 · TA-05 숲 나무 흔들면 곤충 · TA-06 바람 물고기 팔 때 +25% · TA-09 나비 꽃 팔 때 +50% · TA-10 화석 팔 때 +25% · TA-11 친구 그날 처음 말 건 주민 마음 +2. 나쁜 카드 없음은 그대로.
- **야행성 집 「20–5시 열림」**: 달무리는 밤에 광장에도 나가야 해서(D108-A) 19시–22시 반쯤은 밖(문 잠김 = 외출 중), 그 뒤 새벽까지 집 = 들어감. 낮엔 잠(쪽지·노크).
- **노점 덮개 PR-31**: 따로 안 만들고 축제 부스 모델 그대로.
