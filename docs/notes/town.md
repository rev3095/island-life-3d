# W2 P3 주민·상점·박물관 — 작업 노트 (`p3-town` 브랜치)

`src/gameplay/town/` 만 고쳤다. `src/gameplay/index.js` 가 `town/index.js` 를 불러 `init`·`update` 한다.

## 파일

| 파일 | 내용 |
|---|---|
| `index.js` | 모듈 입구. 주민·가게 주인 만들기, 장소 후보(자주 가는 곳) 모으기, 행동 키 등록, 비켜 가기·몸 밀기, `ctx.services.town` |
| `rules.js` | 순수 규칙 (DOM·three 없음): 친밀도 단계, 하루 한 번 말 걸기, 일과(나오는·들어가는 시각), 대사 고르기·조사 붙이기, 부탁·보상, 선물 반응·답례 |
| `people.js` | 주민 6명·가게 주인 2명 설정: 이름표 색, 걸음 빠르기, 일과, 다니는 범위, 자주 가는 곳, 좋아하는 선물, 부탁 종류, 보상 가구 |
| `path.js` | 칸 A* (흙길·광장을 조금 싸게), 곧은 구간 줄이기, 걸음 수 안의 칸 모으기 |
| `actor.js` | 캐릭터 한 명: `applyToonStyle` 모델, idle/walk/run/happy 섞기, 서서히 나타나기·사라지기, 길 따라 걷기 (`world.collide`) |
| `villager.js` | 주민의 하루: 집 → 나오기 → 배회·쉬기 → 문까지 걸어가 들어가기 |
| `talk.js` | 주민 대화 흐름 (잡담·부탁·선물·잘 가), 문 두드리기, `giveItem`(=`data.collect` + 알림) |
| `keepers.js` | 밤톨(상점 문 옆·영업시간)·느루(박물관 문 옆), 첫날 안내, 상점·박물관 흐름, 기증 반응 |
| `labels.js` | 머리 위 이름표 (DOM, 곡면 월드 보정, 창이 열리면 숨김) |
| `lines/*.js` | 대사 데이터 (전부 새로 쓴 문장) |
| `town.test.mjs` | 규칙·대사 데이터·길찾기 확인: `node --test src/gameplay/town/town.test.mjs` |

| 139 | 132 | 133 | 133 | 132 | 141 | 43 | 73 | **926줄** |

주민 묶음: 자기소개 · 시간대 인사 5 · 날씨 5 · 계절 4 · 친밀도 5단계 · 시간대 잡담 · 잡담 13~15 · 집에 가는 길 · 부탁(부탁하기·수락·거절·확인·아직·고마워·보상·오늘은 끝) · 선물(아주 좋아함·좋아함·보통·싫어함·너무 많음·답례·먼저 주기·못 준 것·가방 꽉 참·안 줌) · 잘 가 · 단계가 오를 때 · 사진 · 문 너머(낮·비·눈·밤).
말끝: 코코 '냥', 보리 '멍', 모찌 '깡', 퐁 '꽥', 초롱 '개굴', 두부는 말끝 없이 짧게. 자리 `{item}`·`{want}`·`{reward}` 에 `{item:을}`·`{item:이다냥}` 처럼 쓰면 받침에 맞춰 조사가 붙는다 (`rules.josa`).

## 정한 규칙

- **친밀도** 0~100, 단계 `new 0 · known 10 · friend 30 · close 60 · best 90`. 그날 처음 말 걸기 +2, 선물 아주 좋아함 +6 · 좋아함 +3 · 보통 +2 · 싫어함 0 (하루 두 개까지만 오름), 부탁 들어주기 +6. 100이 되면 `furn.villager-photo` 한 번.
- **답례**: 선물을 받으면 `15% + 친밀도/400 (+15% 아주 좋아함)` 확률로 하루 한 번. 친구(30) 이상이면 그날 처음 말 걸 때 가끔 먼저 준다. 액자(`furn.picture-frame`)는 여기서 나온다.
- **부탁**: 하루 하나 (같은 날 다시 물어도 같다). 주민마다 물고기·곤충·과일·꽃·조개·나무·섬 특산 과일 중에서. 3일 지나면 잊는다. 보상은 40% 가구(주민마다 3종), 아니면 도토리 주머니 2~12개 (`data.collect` 라 바로 지갑으로). 가방이 꽉 차면 다음에 말 걸 때 준다 (`pending`).
- **일과** (5~29시, dayKey 시드로 ±0.5시간): 코코 6~22.5 · 보리 8.5~21 · 모찌 7~21.5 · 두부 5.5~20.5 · 퐁 8~23.5 · 초롱 7~22. 비 오면 보리·모찌·퐁은 집에, 눈 오면 보리·초롱은 집에. 비 오는 날 초롱은 더 자주 뛰고 기뻐한다.
- **배회**: 자주 가는 곳(바닷가·선착장·광장·다리·과수원·연못·강가·꽃 옆·상점·박물관·집 앞) 가운데 무게로 하나 → 칸 A* → `world.collide` 로 걷기. 집에서 `range` 칸보다 먼 곳은 안 간다 (보리 12 ~ 코코 32). 다른 캐릭터는 옆으로 비켜 가고, 플레이어가 바로 앞에 서 있으면 잠깐 기다린다. 가까이 가면 쳐다보고, 오랜만이면 가끔 `happy`.
- **집 드나들기**: 문 앞까지 걸어가 문 안쪽으로 걸으며 0.9초에 사라진다 (`door` 효과음, 거리에 따라 작게). 아침엔 문 안쪽에서 나타나 한 걸음 나온다. 길이 막히면 그 자리에서 사라진다.
- **밤톨**: 상점 문 오른쪽에 서 있고 영업시간(`economy.isOpen`) 밖엔 가게 안(안 보임). 문 앞에서 행동 키 → 인사(가끔 오늘 들어온 가구 소개) → 살래요/팔래요/구경 → `ui.shop.open({ stock, tab })` → 인사. 닫았으면 문 너머 대사.
- **느루**: 박물관 문 왼쪽, 늘 있다. 첫 방문 자기소개 → 기증하러 왔어요 / 이야기 들려주세요 / 다음에. 창이 열린 동안 `museum:changed` 를 모아 닫은 뒤 반응: 첫 기증, 한 점·여러 점, 화석, 5·10·20·30·40점, 분류 완성, 전부 완성(`furn.dino-model` 한 번). '이야기'는 기증한 것 하나의 `desc` 를 읽어 준다.
- **첫날**: `state.flags.intro` 가 없으면 밤톨이 선착장(저장된 자리에서 시작하면 플레이어 곁)에서 1.6초 뒤 먼저 말을 건다 → 조작 안내(키보드/터치 따로, 다시 듣기 가능) → 낚싯대·잠자리채·상점·박물관·주민 소개 → `flags.intro = true`, `town:intro {done}` → 가게로 걸어간다. 물건은 주지 않는다.
- **이름표**: 3.4칸 안 + 창이 닫혀 있을 때만. 문을 드나드는 중엔 안 보인다.
- **몸**: 주민·가게 주인은 단단하다 — 플레이어가 0.5보다 가까우면 `world.collide` 로 벽을 지키며 밀어낸다.

## 행동 키 (gameplay.interactions)

| 이름 | 우선순위 | 언제 |
|---|---|---|
| `town:talk` | 100 | 주민이 1.3칸 안, 앞쪽(0.8칸 안이면 옆도) · 같은 높이 |
| `town:intro` | 100 | 첫날 안내 전, 밤톨 2.2칸 안 |
| `town:knock` | 90 | 주민이 집에 있을 때 그 집 문 앞 |
| `town:shop` | 90 | 상점 문 1.5칸 안(그쪽을 볼 때) 또는 밤톨 1.5칸 안 |

## 계약 제안 (합칠 때 `docs/CONTRACTS.md` 에 반영 부탁)

1. **상점 사는 값이 판매가로 나온다 (T2·T3)**: ui 는 `buyPrice ?? price` 로 읽는데 data 아이템에는 `buy` 칸만 있다. 그래서 낚싯대가 400이 아니라 100에 팔린다 (사서 바로 되팔면 본전). data 아이템에 `buyPrice` 를 같이 넣거나 ui 가 `it.buy` 를 읽게 해 주세요. `economy.buy(id)` 를 ui 가 쓰는 것도 방법.
2. **새 이벤트 `town:intro {done: true}`** — 첫날 안내가 끝났을 때. 튜토리얼 다음 단계(W1 도구 안내 등)가 이걸 들으면 된다.
3. **`ctx.services.town`** (계약 밖, 개발·다른 트랙용): `villagers`, `keepers`, `state(slug)`, `talkTo(slug)`, `debug`.
4. **움직이는 충돌체 (T1 world 에게)**: 지금은 town 이 매 프레임 플레이어를 직접 밀어낸다 (`player.position` 을 `world.collide` 로 옮김). `world.addMover({x, z, r})` 같은 움직이는 충돌체가 있으면 플레이어 충돌이 한 곳에서 처리돼 더 깔끔하다.
5. **재질 투명도 (W4 셰이더 에게)**: 집을 드나들 때 캐릭터 재질의 `opacity`·`transparent` 를 바꾸고 `needsUpdate` 한다. 새 셰이더 재질도 `opacity`·`transparent` 를 받아 주면 그대로 사라진다 (아니면 `materials.setOpacity(root, a)` 같은 도우미를 주면 그걸 쓰겠다).
6. **테스트 위치**: `src/gameplay/town/town.test.mjs` 는 `tests/` 가 T2 폴더라 여기 뒀다. 합칠 때 `tests/town.test.mjs` 로 옮기면 `tests/all.mjs` 가 같이 돌린다 (import 경로 `../src/gameplay/town/…` 로 바꾸기).
7. 아이템 `desc` 를 느루가 읽어 준다 — 설명 문장을 바꿀 때 한 줄 60자 안쪽이면 대화창에 잘 들어간다.

## 확인한 것 (`node dev-server.mjs --port=4192` → `/index.html?debug`)

- 콘솔 오류 없음 (아직 없는 `gather/`·`house/` 404 두 줄은 로더가 건너뛰는 정상 동작). `node --test tests/` 86개, `town.test.mjs` 9개 통과.
- 새 게임: 1.6초 뒤 밤톨 안내 → '한 번 더 들을래요'로 반복 → 플래그 저장 → 밤톨이 다리를 건너 상점까지 걸어감.
- 10시: 주민 6명이 차례로 문에서 나타나 흩어짐. 40초 지켜봐도 끼임 없음. 22:40: 퐁만 빼고 모두 문까지 걸어가 사라짐, 밤톨 가게 안으로. 14시 비: 보리·모찌·퐁 집으로, 초롱 뛰어다님.
- 대화: 처음 만남 자기소개, 잡담, 부탁(보리 '꽃' → 가방 고르기에 꽃만 고를 수 있음 → 도토리 300), 선물(퐁 복숭아 = 아주 좋아함, 코코 잡초 = 싫어함), 먼저 주는 선물 + 가방 꽉 참 → 다음에 받음, 단계 오름 알림(모찌 '아는 사이', 코코 '절친'), 친밀도 100 사진.
- 문 두드리기(비 오는 날 보리), 상점 열림(인사 → 팔기 탭 → 붕어 팔기 → 사기 → 인사) · 닫힘(문 너머 대사), 박물관 첫 방문·첫 기증(암모나이트)·화석 반응·5점·이야기(잉어 설명)·화석 완성·전부 완성 공룡 모형.
- 몸 밀기: 주민 자리에 겹쳐 놓으면 한 프레임에 0.50 떨어진다. 이름표는 3.4칸 안에서만, 대화 중엔 숨김.
- 스크린샷: 공유 노트 폴더 `town-shots/` (01 첫날 밤톨 안내 · 02 모찌 대화 선택지 · 03 비 오는 날 이름표 · 04 보리 이름표).

## 알려진 빈틈

- 주민 집 안은 없다 (문 두드리면 문 너머 대사만). 우편함 편지·선물, 주민끼리 대화, 이사 오고 가기 없음.
- 첫날 안내는 게임을 열자마자 시작해서, 아직 키·클릭이 없으면 소리가 잠겨 첫 줄 목소리가 안 날 수 있다 (audio `unlock` 규칙).
- 나무가 카메라와 주민 사이에 있으면 가린다 (world 의 알려진 빈틈과 같음). 이름표는 나무 위로 보인다.
- 길은 고를 때의 섬 모양으로 찾는다. 걷는 동안 나무를 베거나 새로 놓으면 그 길은 다음 목적지부터 반영된다 (막히면 1.4초 뒤 다른 곳으로).
- 주민이 모여 있으면 이름표가 겹칠 수 있다. 선물 취향을 알려 주는 화면은 없다 (대사로만).
- 상점 사는 값 문제(제안 1)는 ui·data 쪽 수정이 필요하다.
