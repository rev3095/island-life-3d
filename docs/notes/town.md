# W2 P3 주민·상점·박물관 — 작업 노트 (`p3-town` 브랜치)

`src/gameplay/town/` 만 고쳤다. `src/gameplay/index.js` 가 `town/index.js` 를 불러 `init`·`update` 한다.

## 정한 규칙

- **친밀도** 0~100, 단계 `new 0 · known 10 · friend 30 · close 60 · best 90`. 그날 처음 말 걸기 +2, 선물 아주 좋아함 +6 · 좋아함 +3 · 보통 +2 · 싫어함 0 (하루 두 개까지만 오름), 부탁 들어주기 +6. 100이 되면 `furn.villager-photo` 한 번.
- **답례**: 선물을 받으면 `15% + 친밀도/400 (+15% 아주 좋아함)` 확률로 하루 한 번. 친구(30) 이상이면 그날 처음 말 걸 때 가끔 먼저 준다. 액자(`furn.picture-frame`)는 여기서 나온다.
- **부탁**: 하루 하나 (같은 날 다시 물어도 같다). 주민마다 물고기·곤충·과일·꽃·조개·나무·섬 특산 과일 중에서. 3일 지나면 잊는다. 보상은 40% 가구(주민마다 3종), 아니면 도토리 주머니 2~12개 (`data.collect` 라 바로 지갑으로). 가방이 꽉 차면 다음에 말 걸 때 준다 (`pending`).
- **일과** (5~29시, dayKey 시드로 ±0.5시간): 코코 6~22.5 · 보리 8.5~21 · 모찌 7~21.5 · 두부 5.5~20.5 · 퐁 8~23.5 · 초롱 7~22. 비 오면 보리·모찌·퐁은 집에, 눈 오면 보리·초롱은 집에. 비 오는 날 초롱은 더 자주 뛰고 기뻐한다.
- **배회**: 자주 가는 곳(바닷가·선착장·광장·다리·과수원·연못·강가·꽃 옆·상점·박물관·집 앞) 가운데 무게로 하나 → 칸 A* → `world.collide` 로 걷기. 집에서 `range` 칸보다 먼 곳은 안 간다 (보리 12 ~ 코코 32). 다른 캐릭터는 옆으로 비켜 가고, 플레이어가 바로 앞에 서 있으면 잠깐 기다린다. 가까이 가면 쳐다보고, 오랜만이면 가끔 `happy`.
- **집 드나들기**: 문 앞까지 걸어가 문 안쪽으로 걸으며 0.9초에 사라진다 (`door` 효과음, 거리에 따라 작게). 아침엔 문 안쪽에서 나타나 한 걸음 나온다. 길이 막히면 그 자리에서 사라진다.
- **밤톨**: 상점 문 오른쪽에 서 있고 영업시간(`economy.isOpen`) 밖엔 가게 안(안 보임). 문 앞에서 행동 키 → 인사(가끔 오늘 들어온 가구 소개) → 살래요/팔래요/구경 → `ui.shop.open({ stock, tab })` → 인사. 닫았으면 문 너머 대사.
- **느루**: 박물관 문 왼쪽, 늘 있다. 첫 방문 자기소개 → 기증하러 왔어요 / 이야기 들려주세요 / 다음에. 창이 열린 동안 `museum:changed` 를 모아 닫은 뒤 반응: 첫 기증, 한 점·여러 점, 화석, 5·10·20·30·40점, 분류 완성, 전부 완성(`furn.dino-model` 한 번). '이야기'는 기증한 것 하나의 `desc` 를 읽어 준다.
- **첫날**: `state.flags.intro` 가 없으면 밤톨이 선착장(저장된 자리에서 시작하면 플레이어 곁)에서 기다리다 첫 키·터치 0.7초 뒤(소리 잠금이 풀린 뒤라 목소리가 난다, 입력이 없어도 12초 뒤) 먼저 말을 건다 → 조작 안내(키보드/터치 따로, 다시 듣기 가능) → 낚싯대·잠자리채·상점·박물관·주민 소개 → `flags.intro = true`, `town:intro {done}`, 우편함에 환영 편지 → 가게로 걸어간다. 물건은 주지 않는다.
- **주민끼리 수다**: 1.5초마다 2.2칸 안에서 쉬는 두 주민을 35% 로 짝지어 6~11초 마주 보고 번갈아 말풍선 (`{other}` = 상대 이름). 한 번 떤 주민은 45초 쉰다. 그때 말을 걸면 "퐁이랑 수다 떨고 있었어" 같은 인사.
- **편지**: 아침(하루 한 번, 첫날 안내 뒤) — 1~3일 안에 부탁을 들어준 주민은 고맙다는 편지(선물 60%), 친구 18%·단짝 30%·절친 40% 로 편지(선물 50%), 하루 3통까지 (`rules.planLetters`, 같은 날엔 같다). 플레이어 집 우편함 위에 '✉ n' 알림, 행동 키로 차례로 읽고 선물을 받는다. 가방이 꽉 차면 선물만 남은 쪽지로 남는다. 읽은 편지는 30통까지 보관.
- **이름표**: 3.4칸 안 + 창이 닫혀 있을 때만. 문을 드나드는 중엔 안 보인다.
- **몸**: 주민·가게 주인·플레이어를 `world.addMover` 로 올려서 서로 통과하지 못한다 (주민끼리도). `addMover` 가 없는 world 면 예전처럼 매 프레임 플레이어를 밀어낸다.

## 행동 키 (gameplay.interactions)

| 이름 | 우선순위 | 언제 |
|---|---|---|
| `town:talk` | 100 | 주민이 1.3칸 안, 앞쪽(0.8칸 안이면 옆도) · 같은 높이 |
| `town:intro` | 100 | 첫날 안내 전, 밤톨 2.2칸 안 |
| `town:mail` | 91 | 플레이어 집 우편함 1.15칸 안, 그쪽을 볼 때 (문 90 보다 앞, 우편함을 볼 때만) |
| `town:knock` | 90 | 주민이 집에 있을 때 그 집 문 앞 |
| `town:shop` | 90 | 상점 문 1.5칸 안(그쪽을 볼 때) 또는 밤톨 1.5칸 안 |
| `town:museum` | 90 | 박물관 문 1.5칸 안 또는 느루 1.5칸 안 |

W3 집 문(90)은 플레이어 집 문이라 자리가 겹치지 않는다.

## 제안 → 실행한 것 (사용자 요청으로 이 브랜치에서 직접 고침)

1. **상점 사는 값 (T2·T3)**: `src/ui/dom.js` 의 `itemInfo` 가 `data.economy.sellPrice/buyPrice` 를 먼저 쓰고, `src/data/items.js` 아이템에 계약 이름 `buyPrice` (= `buy`) 를 넣었다. 낚싯대 400·소파 3,000 으로 나오고, 덤으로 **섬 특산 과일이 500 이 아니라 100 에 팔리던 것**도 고쳐졌다.
2. **`town:intro {done}` 이벤트·town 서비스·상태 모양**: `docs/CONTRACTS.md` 맨 끝 "2차 W2 (town) 에서 정한 것" 절에 적었다.
3. **움직이는 충돌체 (T1/W1 world)**: `src/world/collision.js` 에 `addMover`, `src/world/index.js` 서비스에 `addMover` 한 줄. W1(`p2-gather`) 이 고친 줄과 겹치지 않는다 (`git merge-tree` 로 확인).
4. **재질 투명도 (W4)**: W4 의 새 `materials.js` 도 `MeshToonMaterial`·`MeshBasicMaterial` 에 패치를 거는 방식이라 `opacity`·`transparent` 가 그대로 먹는다 → 고칠 것 없음. 계약 절에 "이 둘을 살려 둘 것"만 적었다.
5. **테스트 위치**: `tests/town.test.mjs` 로 옮겼다 → `node --test tests/` 에 들어간다 (main 과 합친 지금 114개).
6. **주민 사진 변형 (W3 제안 6)**: W3 가 가방 칸 `variant` 와 `collect(id, n, { variant })` 를 넣어서, 친밀도 100 사진을 `{ id: 'furn.villager-photo', variant: 주민 slug }` 로 준다 → 집에 놓으면 그 주민 사진. 못 준 선물 목록(`pending`)도 `{ id, variant }` 를 받는다.

## 남은 제안

- 상점·박물관은 섬 위에서 창만 여는 방식이라 `ui.fade` 는 쓰지 않았다. 나중에 건물 안 장면을 만들면 W3 집처럼 쓰면 된다.
- 아이템 `desc` 를 느루가 읽어 준다 — 설명 문장을 바꿀 때 한 줄 60자 안쪽이면 대화창에 잘 들어간다.

## 확인한 것 (`node dev-server.mjs --port=4192` → `/index.html?debug`)

- 콘솔 오류 없음 (아직 없는 `gather/`·`house/` 404 두 줄은 로더가 건너뛰는 정상 동작). `node --test tests/` 98개 통과 (town 12개 포함).
- 2차 추가분: 새 게임에서 안내가 첫 키 입력까지 기다렸다가 시작 → 끝나면 우편함 '✉ 1' → 밤톨 환영 편지. 코코(오렌지 선물)·두부 편지 읽기 → 오렌지 받음. 모찌·퐁 광장 수다 말풍선 번갈아 ("꽃이 피었다깡!" / "모찌, 간식 있어꽥?"), 수다 중 말 걸기 → "퐁이랑 수다 떨고 있었어". 느루에게 걸어가면 0.50 에서 멈춤 (움직이는 충돌체 9개). 상점 사는 값 낚싯대 400·벽시계 1,400.
- 새 게임: 1.6초 뒤 밤톨 안내 → '한 번 더 들을래요'로 반복 → 플래그 저장 → 밤톨이 다리를 건너 상점까지 걸어감.
- 10시: 주민 6명이 차례로 문에서 나타나 흩어짐. 40초 지켜봐도 끼임 없음. 22:40: 퐁만 빼고 모두 문까지 걸어가 사라짐, 밤톨 가게 안으로. 14시 비: 보리·모찌·퐁 집으로, 초롱 뛰어다님.
- 대화: 처음 만남 자기소개, 잡담, 부탁(보리 '꽃' → 가방 고르기에 꽃만 고를 수 있음 → 도토리 300), 선물(퐁 복숭아 = 아주 좋아함, 코코 잡초 = 싫어함), 먼저 주는 선물 + 가방 꽉 참 → 다음에 받음, 단계 오름 알림(모찌 '아는 사이', 코코 '절친'), 친밀도 100 사진.

## 알려진 빈틈

- 주민 집 안은 없다 (문 두드리면 문 너머 대사만). 이사 오고 가기, 주민 생일 없음. 수다 말풍선은 소리 없이 글자만.
- 나무가 카메라와 주민 사이에 있으면 가린다 (world 의 알려진 빈틈과 같음). 이름표는 나무 위로 보인다.
- 길은 고를 때의 섬 모양으로 찾는다. 걷는 동안 나무를 베거나 새로 놓으면 그 길은 다음 목적지부터 반영된다 (막히면 1.4초 뒤 다른 곳으로).
- 주민이 모여 있으면 이름표가 겹칠 수 있다. 선물 취향을 알려 주는 화면은 없다 (대사로만).
