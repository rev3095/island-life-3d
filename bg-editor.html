PIPELINE

수정이 반영되는 과정

1. 요소 고르고 요청 보내기

격자에서 요소를 고르고 레퍼런스·프롬프트를 넣어 "요청 보내기". 요청과 파일은 이 페이지의 저장소에 요소별로 남아요.

2. 채팅에서 확인 부탁

채팅에 "배경 요청 확인"이라고 보내주세요. Claude가 새 요청을 모두 읽고 레퍼런스를 내려받아 직접 봅니다.

3. 스펙·모델링 수정 → Blender

숫자·색은 assets/env/specs/<요소>.json(가구는 assets/furniture/specs/)에, 모양 변화는 build_env.py(가구는 build_furniture.py)에 반영하고 node tools/build-env.mjs <요소>(가구는 build-furniture.mjs)로 다시 만들어요.

4. 같은 링크 갱신

새 모델·렌더로 편집기가 업데이트되고, 요청 기록에 "반영 완료"와 바뀐 내용이 적혀요. 확정한 요소는 초록 점으로 바뀌어요.
