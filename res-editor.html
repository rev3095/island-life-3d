요청

반영 순서 · 기록 채팅 명령 "리소스 요청 확인"

  1. 여기서 요청을 남겨요 (저장소 res-requests). 레퍼런스는 res-refs.
  2. 채팅에 "리소스 요청 확인" — Claude 가 새 요청을 읽고 working 으로 바꾼 뒤, 방법대로 처리해요: 스펙 고쳐 다시 빌드 · 로컬 생성 시험 · 만든 파일 교체 · 되돌리기 · 확정/다시 열기.
  3. 교체 약속 검사(이 화면의 표와 같은 것)와 node --test tests/ 를 통과해야 바꿔 끼워요.
  4. 바뀐 묶음만 이 편집기와 게임 링크에 다시 올리고, 요청에 답(done · reply · doneVersion), 반영 기록 applied/res · history/res-v<n> 을 남겨요.
